# Football News Bot — 24/7 через GitHub Actions

Автоматично шукає футбольні новини (трансфери, зміна тренерів, травми), пише пост
українською за заданим форматом, підбирає фото-заглушку і публікує в Telegram-канал
чернеток кожні 15 хвилин. Працює незалежно від будь-якого комп'ютера — хостить сам
GitHub, безкоштовно.

## Що потрібно

1. Акаунт GitHub (безкоштовний) — github.com
2. Ключ Anthropic API — platform.claude.com → "Get your API key". Оплата йде по факту
   використання: токени + $10 за кожні 1000 веб-пошуків. Для циклу раз на 15 хв це
   зазвичай кілька доларів на місяць, але залежить від кількості новин.
3. Telegram-бот, який вже є (token і chat_id ти отримав раніше при налаштуванні через Cowork).

## Кроки розгортання (детально, крок за кроком)

### Крок 1. Створи акаунт GitHub (якщо ще нема)

1. Відкрий https://github.com/signup
2. Введи email, пароль, придумай username → підтверди email, який прийде на пошту.
3. Увійди в акаунт на github.com.

### Крок 2. Створи репозиторій

1. Угорі праворуч натисни іконку "+" → **New repository**.
2. Repository name: `football-news-bot`.
3. Онов "Private" (щоб токен бота і код були не у відкритому доступі).
4. Нічого більше не чіпай (не став галочку "Add a README" — не критично, але простіше без неї).
5. Натисни **Create repository**.

### Крок 3. Завантаж файли з папки `news_bot`

Найпростіше — через веб-інтерфейс, без встановлення git:

1. На сторінці щойно створеного репозиторію натисни **"uploading an existing file"**
   (або "Add file" → "Upload files" у верхньому правому куті списку файлів).
2. Перетягни в це вікно файли `news_bot.py`, `requirements.txt`, `posted_log.json`,
   `README.md` (усі, що лежать безпосередньо в папці `news_bot`).
3. Файл `.github/workflows/news-bot.yml` GitHub-веб-завантажувач іноді "зʼїдає"
   вкладені папки при drag&drop — щоб напевно зберегти структуру, зроби так:
   - Натисни "Add file" → "Create new file".
   - У полі назви файлу введи повний шлях: `.github/workflows/news-bot.yml`
     (GitHub сам створить обидві папки).
   - Відкрий файл `.github/workflows/news-bot.yml` з цієї папки на комп'ютері
     текстовим редактором, скопіюй весь вміст і встав у поле редагування на GitHub.
4. Внизу сторінки в полі "Commit changes" залиш дефолтний текст і натисни
   **Commit changes** (або "Commit new file" для окремого файлу).
5. Перевір результат: у корені репозиторію мають бути `news_bot.py`,
   `requirements.txt`, `posted_log.json`, `README.md`, і папка `.github` з
   `workflows/news-bot.yml` всередині.

### Крок 4. Отримай ключ Anthropic API

1. Відкрий https://platform.claude.com і увійди (можна тим самим акаунтом, що й у
   Claude.ai/Cowork).
2. Якщо це перший вхід — прив'яжи спосіб оплати в розділі **Billing** (API працює
   по передоплаті/постоплаті токенів, приблизно кілька доларів на місяць для
   такого циклу).
3. Перейди в **Settings → API Keys** (або "Get your API key" на стартовій сторінці).
4. Натисни **Create Key**, дай назву (напр. "football-news-bot"), скопіюй ключ —
   він показується лише один раз, одразу збережи його в надійне місце.

### Крок 5. Додай секрети в GitHub-репозиторій

1. У репозиторії відкрий **Settings** (вкладка вгорі репозиторію, не акаунту).
2. Ліворуч знайди **Secrets and variables → Actions**.
3. Натисни **New repository secret** і додай по черзі три секрети (ім'я — точно
   як тут, великими літерами):
   - Name: `ANTHROPIC_API_KEY` → Secret: ключ з кроку 4.
   - Name: `TG_BOT_TOKEN` → Secret: `8513965361:AAFhyP9cO0HRnxdiDDlNpPhFq2K4--NmPv0`
   - Name: `TG_CHAT_ID` → Secret: `-1003763601617`
4. Після кожного — натискай **Add secret**.

### Крок 6. Увімкни GitHub Actions і запусти вручну

1. Відкрий вкладку **Actions** репозиторію вгорі.
2. Якщо GitHub покаже банер про увімкнення workflows — натисни **I understand my
   workflows, go ahead and enable them**.
3. Ліворуч у списку workflow з'явиться **Football News Bot** — клікни на нього.
4. Праворуч натисни **Run workflow** → **Run workflow** (підтвердження на гілці main).
5. Через 10-30 секунд оновиться список запусків — клікни на щойно запущений
   (жовте коло = виконується, зелена галочка = успішно, червоний хрестик = помилка).
6. Клікни на запуск → крок **Run news bot** — розгорни його і подивись лог:
   - `No new news this cycle.` — все працює, просто зараз нема свіжих новин
     під критерії.
   - `Published: ...` — пост пішов у Telegram, перевір канал MVP NEWSPAPER.
   - Помилка (traceback) — скопіюй текст помилки і надішли мені, розберемось.

### Крок 7. Переконайся, що розклад працює сам

Нічого додатково робити не треба: файл `.github/workflows/news-bot.yml` вже містить
`cron: "*/15 * * * *"` — GitHub сам запускатиме workflow кожні ~15 хвилин, 24/7,
незалежно від того, чи увімкнений твій комп'ютер. Перевірити можна в тій же вкладці
**Actions** — там накопичуватиметься історія запусків.

### Крок 8. Вимкни стару задачу в Cowork

Щоб не було подвійних постів (у Cowork і в GitHub Actions одночасно):

1. Повернись у Cowork, відкрий розділ **Scheduled** в бічній панелі.
2. Знайди задачу **football-news-bot**.
3. Вимкни або видали її (в залежності від того, яка опція доступна в інтерфейсі —
   toggle "Enabled"/"Disabled" або кнопка видалення).

## Як це працює

- `news_bot.py` викликає Claude API з увімкненим web-пошуком, дає йому всі правила
  (типи новин, пріоритет ліг, вимоги до підтвердження джерел, формат поста,
  переклад на українську) і список уже опублікованого — просить повернути JSON-масив
  нових постів.
- Для кожного поста скрипт витягує фото зі сторінки джерела (og:image) як
  тимчасову заглушку.
- Постить у Telegram напряму через Bot API (`sendPhoto` / `sendMessage`).
- Після успішної публікації дописує запис у `posted_log.json` і закомічує цей файл
  назад у репозиторій — так дедуп зберігається назавжди між запусками.

## Налаштування, які можна змінити

- Частота запуску — рядок `cron` у `.github/workflows/news-bot.yml`
  (`*/15 * * * *` = кожні 15 хв; GitHub може іноді запускати з невеликою затримкою
  під навантаженням, це нормально).
- Типи новин, ліги, правила підтвердження, формат поста — все в `SYSTEM_PROMPT`
  всередині `news_bot.py`.
- Модель Claude — змінна `CLAUDE_MODEL` (за замовчуванням `claude-sonnet-5`),
  можна задати через секрет/змінну середовища, якщо захочеш дешевшу/потужнішу.

## Важливо

- Стару автоматизацію в Cowork (scheduled task `football-news-bot`) варто вимкнути
  після переходу на цю — інакше можливі дублікати постів, бо в них окремі
  дедуп-логи.
- Фото зараз — сира заглушка з першоджерела (og:image), без обробки. Коли підключите
  генерацію унікальних фото з Figma — просто замініть блок `extract_og_image` /
  виклик у функції `publish()` на власний генератор і підставляйте отриманий URL.
